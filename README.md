## 📌 Overview

The **Kurukshetra Honeypot Server** is an isolated, high-interaction cyber deception environment that acts as the telemetry engine for the threat intelligence platform. It captures malicious attacker reconnaissance, authentication attempts, interactive command execution, and decoy resource access, transforming them in real time into normalized, structured JSON events forwarded to the backend.

```
+-------------------+       +-----------------------+       +------------------------+
|  Attacker Laptop  | ----> |    Honeypot Server    | ----> |   Backend Ingestion    |
| (Member 2 Sim)    |       |   (SSH, Web, API,     |       | (Member 3 API - :8000) |
+-------------------+       |      Decoys)          |       +------------------------+
                            +-----------------------+                   |
                                        |                               v
                                        v                    +----------------------+
                             +--------------------+          | Postgre / Dashboard  |
                             |  logs/events.jsonl |          +----------------------+
                             +--------------------+
```

### 🔒 Safety & Isolation Guarantee
- **Zero Host OS Execution**: All commands executed in the SSH honeypot are safely parsed by an in-memory virtual filesystem emulator. No attacker commands touch the host operating system.
- **Pure Synthetic Data**: All exposed credentials, database dumps, and API tokens are 100% synthetic deception traps.

## 📜 7. Common Event Schema (Contract with Member 3)

Every event generated by the honeypot strictly implements this 9-field contract:

```json
{
  "event_id": "EVT-0001-A1B2C3D4",
  "session_id": "ATK-SSH-99E8F7A1",
  "source_ip": "192.168.50.11",
  "target_ip": "192.168.50.20",
  "service": "ssh",
  "timestamp": "2026-09-11T10:30:00Z",
  "event_type": "command",
  "event": "whoami",
  "metadata": {
    "username": "root",
    "cwd": "/root",
    "command_length": 6
  }
}
```

### Required Fields Matrix:
| Field | Type | Description | Example |
|---|---|---|---|
| `event_id` | `string` | Unique event identifier | `"EVT-0001-99A1BC"` |
| `session_id` | `string` | Correlated attacker session ID | `"ATK-SSH-88B12C"` |
| `source_ip` | `string` | Attacker IPv4/IPv6 address | `"192.168.50.11"` |
| `target_ip` | `string` | Honeypot destination IP | `"192.168.50.20"` |
| `service` | `string` | Honeypot service | `"ssh"`, `"web"`, `"api"` |
| `timestamp` | `string` | ISO 8601 UTC timestamp | `"2026-09-11T10:30:00Z"` |
| `event_type` | `string` | Action category | `"auth_attempt"`, `"command"`, `"decoy_access"`, `"http_request"`, `"api_call"` |
| `event` | `string` | Payload summary / command / path | `"cat /root/fake-credentials.txt"` |
| `metadata` | `object` | Contextual metadata key-value map | `{"user": "root", "method": "GET"}` |

## 🎯 Deception Services & Endpoints

### 1. SSH Honeypot (`Port 2222`)
- Interactive bash shell: `root@corp-app-prod01:~#`
- Built-in commands: `ls`, `cd`, `cat`, `pwd`, `whoami`, `id`, `uname -a`, `ps`, `netstat`, `sudo`, `history`, `env`, `exit`.
- Emulated files: `/etc/passwd`, `/etc/shadow`, `/var/www/html/.env`, `/root/.bash_history`.

### 2. Web Honeypot (`Port 8080`)
- `GET /` & `GET /login`: Enterprise Single Sign-On Portal.
- `POST /login`: Credential harvesting & fake authentication trap.
- `GET /admin` & `GET /dashboard`: Deceptive SuperAdmin control matrix.
- `GET /robots.txt`: Reconnaissance bait guiding attackers to sensitive routes.

### 3. API Honeypot (`Port 8080 /api`)
- `POST /api/login`: Generates synthetic JWT access tokens.
- `GET /api/users`: Leaks synthetic corporate directory.
- `GET /api/admin`: Exposes fake infrastructure control settings.
- `GET /api/config`: Exposes simulated production database & AWS secrets.
- `GET /api/swagger.json`: Deceptive API documentation surface.

### 4. Decoy Resources & Triggers
Whenever any of these decoys are probed via SSH, Web, or API, a high-priority `decoy_access` alarm is generated:
1. `fake-credentials`: Fake root SSH keys, DB passwords, AWS access keys (`/root/fake-credentials.txt`, `/fake-credentials`).
2. `fake-config`: Database connection strings and Stripe secrets (`/fake-config`, `/api/config`, `/var/www/html/.env`).
3. `fake-users`: Synthetic employee database dump (`/fake-users`, `/api/users`, `/opt/backups/fake-users.csv`).
4. `fake-backup`: Fake PostgreSQL SQL database dump (`/fake-backup`, `/opt/backups/fake-backup.sql`).
5. `fake-admin`: High-privilege administrative portal (`/admin`, `/api/admin`).

## 🚀 Quick Start Guide

### 1. Installation

```bash
# Clone and enter workspace
git clone <repo-url>
cd Kurukshetra

# Install dependencies
pip install -r requirements.txt
```

### 2. Configuration (.env)

Copy `honeypot/config/config.env.example` to `.env` or set environment variables:
```bash
HONEYPOT_HOST=0.0.0.0
SSH_PORT=2222
WEB_PORT=8080
BACKEND_URL=http://localhost:8000
```

### 3. Run the Honeypot Server

```bash
python main.py
```
